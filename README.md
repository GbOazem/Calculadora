# 🧮 Calculadora Avançada com Voz (Python)

Este é um projeto de uma **calculadora de terminal em Python** que utiliza a biblioteca `pyttsx3` para **falar os resultados em voz alta**. A calculadora oferece operações básicas e avançadas com uma interface simples em modo texto.

## 🎯 Funcionalidades

- ✅ Soma
- ✅ Subtração
- ✅ Multiplicação
- ✅ Divisão
- ✅ Potência (expoente)
- ✅ Raiz quadrada
- ✅ Porcentagem
- 🔊 Resultado falado com `pyttsx3`

## 📦 Requisitos

- Python 3.6+
- Biblioteca `pyttsx3` instalada

Instale o `pyttsx3` com o comando:

```bash
pip install pyttsx3
🔊 Sobre a voz
A biblioteca pyttsx3 converte o texto em fala localmente, sem necessidade de internet. Ideal para projetos educacionais, acessibilidade ou interfaces faladas.
